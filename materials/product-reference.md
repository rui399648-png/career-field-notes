# 产品策划参考 · 一套可交接的过程

先保存自己的 V1、反馈记录和 V2，再比较。本题全部虚构，没有唯一功能组合答案，工时是模拟估计并已包含实现验收。

## brief 与三方案比较

目标用户：担心设备、基础要求并准备报名的同学。目标动作：看懂能否参加，再完成必要的报名信息。

直接证据：A 不清楚相机要求；B 质疑摄影经历必填。解释/假设：信息难找、填写负担可能是阻碍，但材料没有离开原因，不能断言它们造成漏斗流失。

| 组合 | 工时 | 取舍 |
| --- | ---: | --- |
| 信息卡＋简化表单 | 1+2=3h | 先理解、再填写；暂缓分享卡与 FAQ。 |
| 信息卡＋分享卡 | 1+3=4h | 同时处理理解与传播；表单仍较长。 |
| 简化表单＋FAQ | 2+2=4h | 处理填写与具体疑问；需要让 FAQ 好找，传播仍待后续。 |

这些只是三种合法例子。规则是选择 1–2 项、总计≤4h，不新增账号、不随意改估算。旧版「分享卡3h、其他全部2h、必选2项且≤4h」导致分享永远不可选；新版信息卡1h让信息卡＋分享卡成为真实可行选择。

## V1 → 协作反馈 → V2

V1 选择信息卡＋表单 = 3h。初步拟删除年级和详细摄影经历，保留姓名与手机号。文字线框：活动名→信息卡→报名按钮→活动说明→表单。

| 收到的反馈 | V2 的小决策 | 理由 |
| --- | --- | --- |
| 组织者需要处理传播诉求 | 本轮信息卡集中事实，提出由组织者复制这些事实及占位入口转给同学；成图分享卡暂缓。 | 承认传播需求，也说明这不是交付分享卡；先验证核心理解/填写问题。 |
| 讲师需要区分第一次练习/有过练习 | 详细经历仍删除，交接注明现场自选两组。 | 零基础可以参加；分组需求存在，但不必用长必填文本实现。 |
| 联系方案现在也可邮箱通知，年级无确认用途 | V2 保留姓名与一个邮箱，删除手机号必填和年级；邮箱说明「用于临时变更通知」。 | 已有反馈支持一个必要联系字段；不要求两种联系方式。保留手机号作为唯一联系方式也可以成立。 |

以上表单调整属于给定 2h 范围，不新增通知系统或真实发送通知。组织者要负责现场分组与通知；实际执行前还须确认绝对日期、最终入口、改期/取消流程。

## 验收与交接例子

验收 1：打开页，不展开长介绍即可逐项找到免费、周六14:00–15:00、B203、手机即可、零基础、20名。给出的模拟交付把地点藏到介绍末尾，因此失败；要求把地点加入信息卡后再核对。

验收 2：表单不再强制详细摄影经历或年级，只保留必要姓名/邮箱；邮箱字段旁有临时变更通知用途；空邮箱不能成功提交并提示补填。模拟交付缺少用途说明，因此失败；补说明，再核对必填与错误提示。

验收条件描述要交付的行为，业务指标描述用户结果，不能用「完成率提升」代替功能验收。交接单还应包含范围、工时、事实更新依据、现场分组负责人和未决问题；不要把未选的分享卡悄悄加回范围。

## 指标与模拟复盘

主要指标示例：报名完成率 = 成功提交用户 / 活动页访问用户；同一活动7天、同一批模拟user_id，重复操作每步计一次。18/100 = 18%。观察指标：点击到提交 = 18/40 = 45%；访问到点击 = 40/100 = 40%。

三句复盘示例：「同批模拟用户的报名完成率为18%。我不知道未报名者是否因为信息、表单或其他原因离开，不能据此证明所选功能有效。下一轮先补两三个离开原因访谈或同口径的对照验证，再决定调整哪项。」

这一轮没有真实上线结果。数字不等于你的工作得分；选另一组也可以，只要证据、代价、反馈回应与验收写得清楚。
